# Vite & Gourmand
 ## Presentation de projet

Vite & Gourmand est une entreprise de traiteur située à Bordeaux.
Elle propose divers menus gastronomiques qui s'adaptent à tous les goûts et tous les évènements.

## technologies utilisées
** Frond-end:
-HTML,CSS,JavaSript

**Back-end:
-php

**Base de données:
-MySql,PHPMyAdmin,MongoDB

**Outils:
-GitHub,Figma,Drow.io,Visual Studio Code,XAMPP

## Fonctionnalités:
**Clients:
-Consulter les menus
-Passer une commande
-Se connecter
-Laisser un avis

**emplyés:
-Gérer les menus
-Consulter les commandes
-Valider les avis
 
 **Administrateur:
 -Gérer les emplyés
 -Voir les statistiques
 -Voir le chiffre d'affaires
